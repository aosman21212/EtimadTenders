Etimad Tenders — منصة اعتماد

Automatically fetch Saudi government tenders from tenders.etimad.sa and convert them into CRM opportunities.

Full Tender Details

Every tender is stored with its full metadata: agency name, tender type, activity sector, estimated value, submission deadline, and a direct link back to the Etimad platform for authenticated access.

  • Tender reference and external Etimad ID
  • Government agency and branch
  • Estimated value in SAR
  • Publish date, submission deadline, envelope & offers dates
  • One-click conversion to a CRM Opportunity

Manual Fetch Wizard

Run a manual fetch at any time from the Fetch Tenders menu. Filter by keyword or agency, choose how many pages to pull, and see instantly how many records were created vs. updated.

A daily scheduled action (cron) runs automatically and keeps the database up to date without manual intervention.

Configuration

Configure the integration from Etimad Tenders → Configuration:

  • Page Size — records per API request (max 100)
  • Pages per Cron — how many pages to pull each day
  • Custom API URL — override if Etimad changes their endpoint
  • Session Cookie — optional, for authenticated access
  • Test Connection — verify connectivity in one click

Key Features

Bot Protection Bypass

Smart session warm-up collects F5 TrafficShield cookies from the Etimad listing page so all API calls succeed without CAPTCHAs.

CRM Integration

Convert any tender into a CRM Opportunity with agency, estimated value, and deadline pre-filled — ready for your sales team.

Duplicate-safe Upsert

Existing tenders are updated in-place; only new records are created. Enforced by a unique constraint on the Etimad tender ID.
