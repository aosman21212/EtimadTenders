Key Features

Everything you need to work with Saudi government tenders in Odoo.

1

Auto Daily Fetch (Cron)

Scheduled action pulls the latest tenders automatically every day. Configure pages per run from Settings.

2

Activity / Sector Filter

Fetch only the sectors you care about. 19 sectors synced live from the Etimad API — ICT, Healthcare, Construction, and more.

3

Manual Fetch Wizard

Run on demand with sector, keyword, and agency filters. See a summary of created vs. updated records instantly.

4

CRM Conversion

One click converts any tender into a CRM Opportunity with agency, estimated value, and deadline pre-filled.

5

Bot Protection Bypass

Smart warm-up GET collects F5 TrafficShield cookies so API calls always succeed without CAPTCHAs.

6

Duplicate-safe Upsert

New tenders are created; existing ones are updated in-place. Unique constraint enforced on Etimad tender ID.

How It Works

Five steps from API to CRM opportunity.

  • 1

    Session warm-up — A GET to the Etimad listing page loads F5 TrafficShield cookies, bypassing bot protection automatically.

  • 2

    API call — GET /Tender/AllSupplierTendersForVisitorAsync?TenderActivityId=X returns paginated JSON filtered by sector.

  • 3

    Upsert — Each tender is matched by its Etimad ID. Existing records are updated; new ones are created.

  • 4

    CRM conversion — Click Convert to Opportunity on any tender to push it straight into the CRM pipeline.

  • 5

    Daily cron — A scheduled action repeats steps 1-3 every day for the configured sectors and page count.
