⚙️ How It Works

Five steps from API to CRM opportunity.

  • 1

    Session warm-up — A GET to the Etimad listing page loads F5 TrafficShield cookies, bypassing bot protection automatically.

  • 2

    API call — GET /Tender/AllSupplierTendersForVisitorAsync?TenderActivityId=X returns paginated JSON filtered by sector.

  • 3

    Upsert — Each tender is matched by its Etimad ID. Existing records are updated; new ones are created.

  • 4

    CRM conversion — Click "Convert to Opportunity" on any tender to push it straight into the CRM pipeline.

  • 5

    Daily cron — A scheduled action repeats steps 1–3 every day for the configured sectors and page count.
